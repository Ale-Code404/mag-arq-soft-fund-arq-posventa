# Conclusiones

El Portal de Consulta de Posventa UAN da al propietario un canal de autoservicio para conocer el estado de sus solicitudes y reduce las llamadas y mensajes que hoy atiende servicio al cliente. La solución agrega dos contenedores, la aplicación web y la API de Consulta, y reutiliza el Sistema de Posventa como única fuente de datos, sin cambiar el trabajo de los colaboradores. La API de Consulta protege el sistema interno y aplica en el servidor la regla de que cada propietario ve solo lo suyo. La autenticación por código al correo evita contraseñas y registros nuevos. Las consideraciones para la implementación son dos: confirmar que el Sistema de Posventa puede exponer las dos consultas de solo lectura y depurar los correos de propietarios duplicados o desactualizados antes de abrir el portal.
